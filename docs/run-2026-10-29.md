## 首轮差距来自哪里

1. 首轮仅 Morgan bit + Ridge/ExtraTrees，原始开发集 Ridge=1.005436，未胜
   median=0.974824；只是完成有效参赛，未建立有竞争力的特征/模型基线。
2. 4,905 分子不等于 4,905×4 标签。仅 41 分子四标签齐全；主表偏向筛选命中，
   而盲测是类似物扩展、四终点全部测量。低活性与缺失终点的分布差异仍是风险。
3. 目标是实验拟合的 pIC50 与可信区间。普通点平方损失不完全对应官方区间外
   绝对距离。本轮区间 SVR 在 CYP3A4 开发集优于普通 count-SVR，但未胜固定集成，
   没有为了方法叙事强行采用它。
4. 增加描述符和相似性核、改为逐终点选型，能够在同等硬件下明显优于原 Ridge。
   CYP1A2 的树模型非常接近（Hist=0.801047，ExtraTrees=0.801635），不把微小差距
   解释成稳健的机制结论；CYP2D6 仍最弱。
5. 开发集误差分层显示：CYP2D6 选中 SVR 在 pIC50<4 层的平均区间外距离
   为 0.8027，原 Ridge 为 0.6352；整体改善主要来自 >=4 层。CYP1A2 低活性层也
   未改善。这是冻结后的诊断，不再据此变更本轮选择；盲测稠密标签可能放大该缺点。

TDI 表审计没有新增直接抑制标签；Emax/单浓度属于辅助实验结果，未作测试输入。
审计与文件哈希见 [round2-aux-audit.json](round2-aux-audit.json)。无专有或外部数据。

## 冻结后的附加诊断（不影响本轮选择）

按真实训练标签计算，CYP2D6 的 pIC50<4 占比仅 8.64%；本轮盲测**预测**中
该占比为 0.27%，首轮为 14.53%。后两者是模型输出分布，不是已知盲测真实占比，
不能反推测试标签或拿来校准预测。它提示模型向命中富集训练分布收缩的具体风险。

在复用的 seed=42 上，对分子骨架做 1,000 次配对 cluster bootstrap，重新计算
两模型的官方分母，宏平均 ST-RAE 差（本轮−Ridge）的百分位区间为
[-0.3285, -0.2269]。这是**选型后**诊断，不校正候选选择乐观偏差，不提供独立
泛化置信区间；只说明该开发切分的改善不由个别骨架完全驱动。完整计算结果
保存在最终 run 的 `bootstrap-diagnostic.json` 和 `label-distribution-diagnostic.json`。

后续研究优先考虑采样偏差及辅助训练数据如何安全使用，尤其是：单浓度数据的
训练侧预训练/折外预测、缺失标签的选择机制、与命中类似物相符的补充验证。
这些是未执行的研究方向，不声称已经得到新模型或更高成绩；不依据公榜调参，
不把辅助实验数值直接当作缺失 pIC50，不自动启用付费算力。

无标签特征审计显示：全训练集到盲测集的 MolWt/MolLogP/TPSA/芳香环数均值差，
以训练标准差计分别为 -0.180/+0.039/+0.064/+0.114，整体均值偏移不大。
但 CYP2D6 **已测子集** 到盲测的 MolLogP/TPSA 差为 -0.249/+0.373；
只看全体训练分子会掩盖终点条件下的分布差异。均值比较不能证明全分布一致，
也不能证明任何测试标签分布。数据留在最终 run 的 `covariate-diagnostic.json`。

本轮**选型和上传后**只读回查首轮官方分项（精确匹配首轮方法链接），
结果为 CYP1A2/2C9/2D6/3A4 ST-RAE = 0.890109/0.693074/1.487283/0.643528。
CYP2D6 的官方 R²=-1.0233，确认为首轮最主要的拖累。该回读只作诊断，不修改
已经冻结、上传的第二轮模型/预测；见 [first-round-endpoint-diagnostic.json](first-round-endpoint-diagnostic.json)。
