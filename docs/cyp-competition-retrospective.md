# 一次CYP盲测参赛：从指纹基线到预训练模型的验证与失败诊断

本项目是个人AIDD学习与竞赛工程，参加OpenADMET CYP 2026直接抑制回归赛道。
目标是从分子结构预测四种酶的抑制效力，并留下可以复查的研究过程。本文区分官方
已评分提交、反复使用的本地开发结果及工程验证；不将任一项替代其他项。

截至2026-11-02的[官方回读与提交核验](final-submission-audit.json)，本项目第二轮
提交仍有效，MA-ST-RAE为**0.9201311431**，实时公开榜214/267。首轮为0.9284982814，
第二轮相对误差下降约0.90%。这两次已获官方评分的提交中，第二轮成绩较好，当前
有效条目也正是它。比赛尚未结束，实时榜不是最终成绩或隐藏榜表现。

最后一轮已完成：冻结神经头宏开发ST-RAE0.777805，有限编码器微调0.797010，
都未超过指纹/描述符基线0.770835。微调降低了2D6低层误差，却越过高层恶化上限，
没有可信替换依据。因此不打开确认、不再提交，保留第二轮有效条目并结束候选搜索。

## 数据并不是随机划分的普通回归表

[官方数据](https://huggingface.co/datasets/openadmet/cyp-challenge-train-test)锁定revision
`d7eb3c973dca01aad8e33c91c29e5123fd925d8f`，训练主表4905分子，测试750分子。
训练标签覆盖CYP1A2/2C9/2D6/3A4分别1412/1285/1493/2335，只有41个分子四终点齐全。
测试公开分子编号与SMILES，真实实验标签由主办方保留。

主办方先从化合物库做单浓度初筛，再对命中分子做12点剂量—响应实验，以曲线
拟合得到pIC50及不确定区间。测试则从1A2/2C9/3A4各25个强命中出发，购买相似物，
构成750分子的扩展集，再密集测定四种酶。2D6没有参与这些测试种子的选择。
训练富集命中、标签稀疏，测试为类似物扩展、终点密集，二者的抽样过程不同。
[官方实验与数据构建说明](https://openadmet.ghost.io/announcing-openadmets-cyp-inhibition-blind-challenge/)

这解释了两项约束。首先，缺失pIC50不能填零，初筛未命中也不能直接改成已知
不活跃。其次，按骨架划分本地验证虽然限制了某类结构泄漏，却不自动重建比赛的
目标分布。验证拆分必须与用途一起解释。

pIC50=-log10(IC50，以mol/L计)，数值越高，达到半数抑制所需浓度越低。
但pIC50低于可靠检测范围时，点估计可能很不确定。赛事主指标MA-ST-RAE采用可信
区间外距离，再进行相对化和终点宏平均；不是普通MAE。项目锁定并复用官方评分实现。
固定测试数据身份、原始SMILES、四列有限预测及750唯一行，是提交合同而非研究效果证明。

对单个终点，令区间为`[l_i,u_i]`、预测为`p_i`，则
`d_i(p)=max(l_i-p,0)+max(p-u_i,0)`；ST-RAE为
`sum_i d_i(p_i) / sum_i d_i(mean(y))`，再对四终点等权平均。
落在区间内的预测误差为零；ST-RAE=1表示与在该评估集上始终预测标签均值相当。
训练表的`*_conf_low/high`提供这个评分区间，不能作为测试时可用的输入。
辅助单浓度`log2fc`是另一种测量，既不是pIC50，也不是已知pIC50的缺失值填补器。

## 实际有效提交使用什么

第二轮提交只使用官方主训练数据，没有使用外部活性、预训练权重或后续失败模型。
从SMILES提取Morgan radius2的2048位指纹、2048维log1p计数指纹和217项RDKit二维
描述符；原始SMILES保持不变。逐终点排除缺失标签，独立选择模型：

| 终点 | 已提交模型 |
|---|---|
| CYP1A2 | 描述符HistGradientBoosting |
| CYP2C9 | 计数SVR/混合特征ExtraTrees/描述符梯度提升，固定50/25/25权重 |
| CYP2D6 | 位指纹Tanimoto SVR(C=1) |
| CYP3A4 | 同2C9的固定集成 |

候选预算共10个，按三次骨架开发划分的官方指标选型；不是三个独立测试。模型在
全量已测训练标签上重训后，生成750×6预测并通过本地与官方validator。
[公开且版本化的方法报告](https://github.com/cylovelife/aidd-agent/blob/01b451df45e915c28b70a065e676f38ff9b15767/docs/method-report-round2.md)
和[真实接收/评分](submission-round2.md)分别留档。

## 为什么本地改善没有转化为同等盲测收益

第二轮本地25.33%的改善只对应既定开发划分。官方2C9/3A4改善，1A2/2D6退步，
宏平均只小幅改善。这支持检查采样和适用域，不支持把更多同类调参视作必然答案。

第三轮起主表与官方辅助表的身份并集为4906分子；多出的身份没有因此获得直接
pIC50标签。在这个并集上保留963分子确认分区，开发池3943分子，使用两个骨架
切分加一个类似物压力切分。后者按设计保留强活性训练锚点、允许共享部分骨架，
但仍无法重建真实盲测的
相似度分布：最近训练分子Tanimoto中位数约0.422，盲测无标签诊断约0.587。
这些开发集被后续轮次反复使用，选择乐观偏差仍存在。确认分区从第三轮起未评估，
但部分样本在更早研究中曾使用，不能宣传为历史上从未接触的独立测试。

2D6低活性标签覆盖尤其不足。辅助初筛表中log2fc>=0的2520个2D6观测没有对应真实
直接pIC50标签；它们不能被自动变成负例或精确上界。辅助任务能改变表示，不能
凭空提供校准真值。没有足够标签覆盖时，统计方法也无法验证整个缺失区域的可靠性。

## 外部数据需要先恢复实验含义

第四轮下载了19004条原始活动记录。来源内去重与排除后，10736条辅助任务记录
来自两个不同实验域；它们不是同一体系下的赛事标签。保留底物、酶制备、单位、
预孵育、时间与不等号，不能把不同实验中的IC50不加区分地混合。

低活性数字往往来自超实验范围的曲线外推。第五、六轮检查原文与SI，有的只能支持
IC50大于某测试上限，即单侧pIC50约束；有的单位、结构映射或响应证据仍不完整，
必须隔离。6条可靠界限仍覆盖不足，不能因花了文献核验时间就降低模型准入标准。
同样，几次失败只说明当前来源与方法不足，不能推断所有外部数据或删失学习都无效。

## 预训练模型失败如何被定位

第七轮CheMeleon使用公开MIT权重、冻结编码器、均值聚合2048维向量，再接fit-only
StandardScaler与Ridge(alpha10)。宏开发ST-RAE2.184158，差于指纹基线0.770835。
第八轮先检查权重、缓存哈希、结构顺序和历史预测复现，没有发现错位证据。

原头只有817–1528个fit标签却拟合2048维输入。训练RMSE0.039–0.135，验证却到
0.973–10.117；部分稀有激活维度经训练折标准化后，在验证上的绝对幅度达到数千，
有标签验证分子出现约-44至103的pIC50外推。高维拟合过度和标准化外推不稳定，
比“预训练不适合化学”这种笼统判断更具体，也可以通过干预检验。

只加强正则、只限制标准化输入、两者组合的2x2对照，把组合头宏ST-RAE降到
0.816015，相对原头下降62.64%，但仍未超过指纹基线。2D6低层改善19.06%，高层
恶化11.09%，违反预定保护条件。这里改的是输入，不是事后截断预测或修饰评分。
这证明读出头配置是重要失效因素，仍不能把全部剩余差距归因于它。

最后一轮进一步比较相同小型神经头下的冻结表示和最终原子投影微调。资源探针不用
CYP标签评分，正式训练预算先冻结；早停仅在外层fit内部选择，之后重新初始化重训。
没有因前几轮失败而放宽确认或提交门槛，也没有把公榜变成候选搜索器。

该对照只有一个固定种子，微调仅开放最终投影，不能检验全量图网络训练的上限。
公开检查点的预训练语料是否与赛事分子逐一重叠也未完全确定；哈希核验保证了所用
权重可追踪，不保证预训练语料完全独立。小幅开发集差异不能据此解释为普遍优势。

## 怎样理解“保留自己的最好成绩”

可核验的含义是：本项目所有已获官方评分的提交中，当前有效条目的公开分数最低；
预测哈希与原回执吻合，方法报告公开可读。它不意味着尝试了所有模型，也不意味着
知道未提交候选的隐藏分数。后续候选仅有本地开发结果时，无法声称盲测一定更好。
比赛尚未结束，不能报告最终名次或用实时榜证明药物发现能力。

保存当前提交也有实际意义：平台按最新有效提交计分，后续更差提交可能替换已有
条目。本项目要求先通过开发和一次确认，再进行真实上传。若最后一轮没有可信增益，
不以临近截止为由增加一次无依据的上传。

## 复现入口与这次实践留下的能力

环境由pyproject.toml与uv.lock定义；主数据及上游版本见sources-lock.json。基础命令：

```bash
uv sync --frozen
uv run aidd fetch
uv run aidd optimize --output-dir state/runs/my-round2
uv run aidd validate state/runs/my-round2/regression.csv
uv sync --frozen --group representation
uv run --group representation python scripts/run_final_neural.py run \
  --output state/runs/my-final-neural
```

最后一轮依赖已保存的第七轮结构向量、原预测和公开权重，具体文件/哈希及门槛见
[冻结方案](final-round-plan.md)。新目录拒绝覆盖；state不随Git分发，重现实验需先
按对应方案准备公开数据与缓存。仅有源码不能声称已复现所有手工文献审计证据。

这次实践训练的是几个可迁移环节：把实验定义转成数据合同；识别采样偏差和泄漏；
从简单基线开始设计有限对照；用预测与梯度定位异常；保留负结果；让研究结论与
平台回执、软件测试各自对应。代码和报告可以作为后续独立复现、讨论和学习的材料，
个人是否掌握这些能力还需要独立实现与讲解来检验。
