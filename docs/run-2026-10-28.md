## 复现与文件

```bash
uv sync --frozen
uv run aidd fetch
uv run aidd baseline --output-dir state/runs/reproduction
uv run aidd validate state/runs/reproduction/regression.csv
uv run pytest
uv run ruff check .
uv run ruff format --check .
uv run mypy src/aidd_agent
```
